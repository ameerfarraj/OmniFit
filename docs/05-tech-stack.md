\# טכנולוגיות הליבה ותזרים עבודה (Tech Stack \& Workflow)



כדי להבטיח מערכת סקיילבילית, יציבה ומוכנה לצמיחה ולשילוב AI עתידי, הפרויקט ייבנה על בסיס טכנולוגיות התעשייה הבאות, תוך דגש על פיתוח חוצה-פלטפורמות ותשתיות ענן.



\## 1. אפליקציית הלקוח (Frontend - iOS \& Android)

כדי להימנע מתחזוקת שני קודי מקור נפרדים, הפיתוח ייעשה בטכנולוגיית Cross-Platform המייצרת אפליקציית Native גם לאפל (App Store) וגם לגוגל (Play Store):

\* \*\*סביבת פיתוח:\*\* React Native (בשפת TypeScript) או Flutter (בשפת Dart).

\* \*\*ניהול מצב (State Management):\*\* Redux Toolkit (ב-React) או Bloc/Riverpod (ב-Flutter) לניהול חלק של הנתונים בזמן שהאפליקציה פתוחה.

\* \*\*אפיון ועיצוב מסכים:\*\* Figma (כל מסך יעבור שרטוט ואישור לפני הקידוד בפועל).



\## 2. ארכיטקטורת שרת (Backend)

\* \*\*טכנולוגיה:\*\* ASP.NET Core Web API (C# / .NET 8).

\* \*\*גישה לנתונים:\*\* Entity Framework Core (EF Core) מבוסס Code-First.

\* \*\*ארכיטקטורה פנימית:\*\* 3-Tier (UI, BLL, DAL) מבוססת Domain-Driven Design למניעת תלות קשיחה בין מודול התזונה למודול האימונים.



\## 3. מסד נתונים ושירותי ענן (Database \& Cloud Infrastructure)

כדי לא להכביד על השרת המרכזי וכדי להוזיל עלויות פיתוח, נשתמש בשירותים מנוהלים:

\* \*\*מסד נתונים (SQL):\*\* PostgreSQL. מנוע רלציוני חזק וחינמי לאנטרפרייז, אידיאלי לשאילתות מורכבות על יומני אימונים.

\* \*\*ניהול משתמשים ואותנטיקציה:\*\* Firebase Authentication או Auth0. (חוסך חודש של פיתוח מנגנוני שחזור סיסמה, התחברות עם גוגל/אפל ואבטחת טוקנים).

\* \*\*התראות (Push Notifications):\*\* Firebase Cloud Messaging (FCM) לשליחת התראות בזמן אמת למאמנים ומתאמנים.

\* \*\*אחסון מדיה (Storage):\*\* AWS S3 או Cloudinary. כל תמונות ה-Check-in וסרטוני הטכניקה יישמרו כאן (ולא במסד הנתונים!), השרת ישמור רק את הלינק (URL) לקובץ.



\## 4. תזרים פיתוח וניהול קוד (Git Workflow)

\* הפרויקט מנוהל בשיטת \*\*GitHub Flow\*\*.

\* ענף ה-`main` מוגן. אין לדחוף אליו קוד ישירות.

\* כל מודול או פיצ'ר יפותח בענף ייעודי (למשל: `feature/user-auth`).

\* מיזוג ל-`main` יתבצע רק לאחר פתיחת \*\*Pull Request (PR)\*\* ואישור (Code Review).



\## 5. בדיקות תוכנה (Unit Testing)

\* שימוש ב-\*\*xUnit\*\* לבדיקות יחידה ו-\*\*Moq\*\* לדימוי (Mocking) של מסד הנתונים ב-C#.
